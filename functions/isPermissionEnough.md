# Function: isPermissionEnough()

> **isPermissionEnough**(`requiredPermission`, `permission`): `boolean`

Checks if a users board permission is greater (or equal) to a provided required permission.

## Parameters

### requiredPermission

`BoardMemberPermission`

The required permission level.

### permission

`BoardMemberPermission` = `haptic.currentUser.permission`

The permission to check (defaults to the current user's permission).

## Returns

`boolean`
